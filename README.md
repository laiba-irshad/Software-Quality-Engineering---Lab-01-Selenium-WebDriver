# SQE Lab 01 - Selenium WebDriver Navigation

This lab focuses on browser navigation using Selenium WebDriver and Python.

## Requirements
- Python 3
- Google Chrome
- Selenium WebDriver

## Exercises
1. Navigate between multiple websites.
2. Perform browser back and forward operations.
3. Refresh a webpage and verify its title.
4. Test complete browser navigation.

## Topics Covered
- WebDriver Setup
- driver.get()
- driver.back()
- driver.forward()
- driver.refresh()
- driver.title
- driver.current_url
- driver.quit()

## Installation

```bash
python -m pip install -U selenium
```

## How to Run
Run each Python file separately using the VS Code terminal.

## Objective
To understand and practise basic browser navigation and control using Selenium WebDriver.
